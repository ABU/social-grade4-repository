# 家鄉小偵探：四上社會複習

## 發佈至 GitHub Pages

1. 登入 GitHub，建立公開 repository（例如 `social-grade4`）。
2. 選 **Add file → Upload files**，上傳本資料夾內的 `index.html` 和 `.nojekyll`，然後 **Commit changes**。請讓 `index.html` 位於 repository 最上層，不要整個外層資料夾一起上傳。
3. 開啟 **Settings → Pages**。
4. 在 **Build and deployment**，Source 選 **Deploy from a branch**。
5. Branch 選 **main**，資料夾選 **/ (root)**，按 **Save**。
6. 等待 Pages 發佈完成，回到此頁查看網址。一般形式是 `https://你的帳號.github.io/social-grade4/`。

不用 npm、API 金鑰或付費主機。`index.html` 是完整單檔，雙擊也可離線作答。更新時只需覆蓋此檔並 commit。

## 內容與資料依據

- 共96題：各單元24題，每單元含12題原練習、8題圖表判讀與4題閱讀推理；每單元基礎、應用、判讀探究各4題。
- 單元練習、隨機12題綜合挑戰、錯題複習、逐題答案與解析。
- 手機適用，無時間限制；紀錄存於目前瀏覽器的 localStorage。
- 依大崙國小115學年度康軒版第三冊社會課程計畫核對單元及學習主題。
- 參考永安國小114學年度四上社會期中與期末公開試卷的重疊考點及題型。原試卷沒有明示教材版本，不把它當成已確認的康軒官方試題。
- 所有題目重新編寫，不重製課本、學校试卷圖片或原題全文。情境判讀為自編延伸；標為練習資料的數據是虛構。
- 並未逐頁檢閱115正式課本全文，因此這是課程計畫範圍的複習工具，不是官方教材或實際試卷。

完整來源、對應說明與查閱日期已放在網頁底部，可展開查看。學校實際考試範圍請再對照老師通知。

## 修改題庫

`index.html` 的 `const bank` 包含96題，每題含 id、unit（0至3）、level（1至3）、q、options、answer、explanation、source。答案文字必須與一個選項相同；題目 id 不可重複。選項每次重新排列。

檢索日期：2026-10-06。本套檔案沒有發佈至任何外部帳號；由你上傳即可。

## 第三版：四單元一致的題型

全站96題，每單元24題：原12題、8題附圖或表格判讀、4題閱讀推理。第一單元用兩張地圖；第二單元用三合院平面圖與器物比較表；第三單元用老街配置圖與店鋪變遷表；第四單元用行事曆與作息圖。所有圖表均為自編教學示意或練習數據，不是原課本圖片。單元1新增題保留；單元2至4閱讀題保留，再各加8題圖表。網頁仍為單檔，不須另外上傳圖片。
